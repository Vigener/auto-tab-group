# Auto Tab Group

Cmd+クリック（または中クリック）でリンクを開いた際、自動で親タブと同じグループにまとめる Chrome 拡張機能です。  
Dia Browser や Zen Browser のタブスタック／自動グループ化に近い使い心地を Chrome / Chromium ブラウザで再現します。

## 特徴

- **Cmd+クリックで即グループ化**:
  - 親タブがグループ未所属の場合: 親と開いた子タブの両方を含む新しいグループを作成。
  - 親タブが既にグループ所属の場合: そのグループ内に子タブを追加。
- **ミニマル＆クリーン**:
  - デフォルトではグループ名を自動付与せず、無名のシンプルなグループを作成します（余計な長いタイトルでタブバーが圧迫されません）。
  - ポップアップメニューから「親タイトルを名前に適用」をいつでも ON/OFF できます。
- **超軽量＆安全**:
  - 外部通信なし、トラッキングなし、不要な権限なし（`tabs`, `tabGroups`, `storage` のみ）。

## インストール手順

1. 本リポジトリをクローンまたはダウンロードします。
2. Chrome を開き、アドレスバーに `chrome://extensions/` と入力して開きます。
3. 画面右上の **「デベロッパー モード」** を ON にします。
4. 画面左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. 本フォルダ（`auto-tab-group`）を選択します。

## 設定

拡張機能のツールバーアイコンをクリックすると設定ポップアップが開きます。

- **親タイトルを名前に適用** (デフォルト: OFF):
  ON にすると、新規グループ作成時に親ページのタイトルをグループ名として設定します。
